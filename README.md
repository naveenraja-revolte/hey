# Calculator

A responsive, keyboard-friendly calculator for everyday arithmetic. It supports decimals, parentheses, and standard order of operations; calculations are handled in the browser and are not saved.

## Run locally

Install dependencies and start the development server:

```bash
npm ci
npm run dev
```

Open http://localhost:3000.

Use the on-screen keypad or your keyboard. Press Enter or `=` to calculate, Backspace to delete the last character, and Escape to clear.
